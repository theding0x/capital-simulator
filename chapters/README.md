# Chapters

This directory holds an HTML summary for each chapter of *Capital, Volume I* that we implement in the simulator. The naming convention is:

```
chapters/NN-<short-slug>.html
```

For example:

```
chapters/01-the-commodity.html
chapters/02-exchange.html
chapters/03-money-or-the-circulation-of-commodities.html
```

Each chapter HTML should include:

1. A short prose summary of Marx's argument in that chapter.
2. A list of the new economic concepts introduced.
3. A description of how those concepts are represented in the simulation (which services, types, and endpoints).
4. (Optional) Diagrams or tables that help illustrate the chapter's ideas.

The pull request that introduces a chapter should reference its HTML file in the description.
