# commodity-service

The simulation's model of the **commodity** — the cell-form of bourgeois wealth from which Marx begins *Capital* Vol. I.

This service will own:

- The dual character of the commodity: **use-value** and **value**.
- **Exchange-value** as the form in which value appears.
- **Socially necessary labour-time** as the substance of value.
- The fetishism that arises when relations between people take the form of relations between things.

- Default port: `8081`
- Persistence: MongoDB (via `pkg/mongo` once chapters require it)

Run locally:

```bash
make run-commodity-service
```
